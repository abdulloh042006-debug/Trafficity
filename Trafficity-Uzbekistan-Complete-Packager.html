2. ZIP

The ZIP is built only after every file exists and its size and SHA-256 match the manifest. Entries are sorted and use fixed timestamps, so the same input gives the same bytes. The manifest's own digest is exempt (self-reference).

3. GitHub Direct Push

Use a fine-grained, repository-scoped, short-lived token with Contents: Read and write for this repository only. The token stays in memory for the duration of one push, is sent only to api.github.com as an Authorization header, and is cleared afterwards. Never commit it. This page does not store it.
